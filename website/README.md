# Richcordly Website

The official, sleek single-page download portal for [Richcordly](https://github.com/SpoiledUnknown/Richcordly).

## Features
- **Dynamic GitHub Releases API**: Automatically queries and surfaces the latest release version, asset downloads, and file sizes.
- **Platform Selector**: Windows & Linux downloads, with macOS marked as coming soon.
- **Nocturnal Violet Theme**: Follows Richcordly's dark navy & electric violet design language with glassmorphism and ambient glows.
- **Zero Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript.
- **GitHub Pages / Desktop Ready**: Deployable directly to GitHub Pages or manageable via GitHub Desktop.

## Local Preview
Simply open `index.html` in any modern web browser or serve via:
```bash
npx serve .
```
